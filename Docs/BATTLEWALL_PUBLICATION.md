# BattleWall 展示范围

本页配套 /zh/projects/battlewall/ 和 /en/projects/battlewall/。

- 定位：参与开发的 Unity 多人合作 PvPvE 攻城战游戏，非开源团队项目。
- 个人工作：输入模式、载具交互、基于 Netcode 的状态同步、死亡复活时序；表述为参与工作，不把完整游戏或美术归为个人独立作品。
- 来源：用户提供的项目复盘资料与游戏录屏。资料未经本网站重新审计源码或运行联机测试。
- 发布内容：人工整理的中英文机制摘要、取舍、裁切后完整时长游戏演示和封面。
- 未发布：原始技术文档、其中的实现代码/内部接口/问题清单、面试准备文档、简历草稿、未裁切录屏、游戏源码和可运行构建。
- 原始录屏含编辑器与日志。网页视频并排展示同一录屏中两个本地连接 Unity 编辑器的可见游戏区域；原窗口重叠导致可见范围不同，编辑器面板与日志不展示，不改变播放顺序或速度，保留原音轨；原始容器元数据已移除。原录屏与原文档未被修改。
- 没有声称项目开源，也不附游戏源码仓库链接；没有把设计目标或估算写为实测性能提升。
- 游戏及媒体归各自权利人所有，不适用 XUILab 的 MIT 许可。公开展示不构成额外再分发授权。
- 文件清单及校验值位于 public/media/battlewall/manifest.json。公开媒体目录仅应含 demo-dual.mp4、poster-dual.jpg、manifest.json 与 NOTICE.txt。
- 视频画面抽样检查和完整解码验证属于媒体检查，不等于浏览器播放、联机正确性或性能测试。

## 展示修订

- 双端画面来自相同源帧，保留本地多人联机语境，不虚构 Host/Client 归属。
- 四项贡献各补充问题背景、处理流程、3–4 项实现工作、具体场景及取舍。没有公开原始实现代码或面试材料。
