# 项目范围

个人站点：`https://xiaoran6657.github.io`。独立于 XUILab 的展示网站。

## 已确认需求

- Astro 静态站 + TypeScript + CSS，通过 GitHub CLI 管理远端，GitHub Actions 发布到 GitHub Pages。
- 中英双语，按钮切换；浅色、深色与默认随系统的主题按钮。
- 名字、职业定位、简介、简历和联系方式可在配置文件修改。
- 首版使用 xiaoran6657、“Unity / UI 工程探索”和 GitHub 联系入口；邮箱与简历留空隐藏。这是用户确认的默认值。
- 展示第一个开源项目 XUILab：概览、三个技术案例、真实截图、可手动播放的视频、结果与源码/下载入口。
- 首页强调作品，详细工程证据留在案例页和上游文档。

## 内容边界

只使用 XUILab `v0.1.0-preview.1` 的公开交付资料与已核对媒体，不公开私人简历、原始机器日志、PM 或私人参考资料。不推断个人任职经历或独立实现/掌握程度。

不添加后台、CMS、分析工具、登录、联络表单或未有内容的占位项目。简历是可选的真实链接，没有伪造下载文件。

## 交付目标

本地可构建、可维护；源代码和锁文件保存在本仓库；GitHub 上公开源码并由 Pages 提供站点。视觉、移动端与真实视频播放验收如开展，应独立记录证据。
