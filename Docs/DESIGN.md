# 设计与实现

## 视觉方向

采用清晰的工程作品索引：冷白/深炭色表面，青柠色小面积强调，宽留白、大标题、项目原始图像。首页先建立身份与研究方向，再进入 XUILab 主项目和三个案例。页面不用虚构项目、统计或经历填充。

使用系统字体避免外部字体下载。正文约 16px，说明文字约 14px，少量编号和版本信息约 12px。长文本自然换行；小屏单列展示；不做自动播放或装饰动画。系统减少动态效果偏好得到尊重。

## 路由

每个下列页面都有 `/zh/` 和 `/en/` 版本：

| 相对路径 | 内容 |
| --- | --- |
| / | 身份、精选作品、三个案例、关于入口 |
| projects/ | 作品索引 |
| projects/xuilab/ | 项目概览、结果分类、测量边界与资源 |
| projects/xuilab/list-lab/ | 列表案例与视频 |
| projects/xuilab/gradient-lab/ | 渐变案例与视频 |
| projects/xuilab/benchmark-runner/ | Runner 案例与视频 |
| projects/battlewall/ | 非开源团队作品、个人贡献摘要与裁切演示 |
| about/ | 配置化身份、公开项目方向与联系入口 |

根路径提供语言偏好跳转与无 JS 中文内容；404 页面提供双语返回链接。每个语言页面有 title、description、canonical、hreflang、OG 文本元信息，并列入 sitemap.xml。

## 交互

- 语言按钮指向当前路由的另一语言，不依赖 SPA；JS 增强保存偏好与锚点。
- 主题默认随 `prefers-color-scheme`，首次绘制前尝试应用已存偏好；按钮循环自动/浅色/深色，自动模式实时响应系统变化。
- 关闭浏览器存储不会使页面失效。无 JS 时仍可读全部正文并通过普通链接导航，CSS 跟随系统主题。
- 视频使用原生播放、暂停、音量/进度控件能力，preload=none；邻近文案说明 45 秒、无音轨和非实时性质，并提供时间点说明。
- 图片可按原分辨率打开，提供替代文本、尺寸和延迟加载。上游英文图内标签保持原样。

## 数据与媒体

公开资料配置与 XUILab 内容分开存储。作品页保留独立 Player 测量条件、全部对照分类和不确定结果。每个媒体文件保留上游 SHA-256；网页资源路径全部位于本站。

网站可从纯源码与 npm 锁文件独立构建，不需要 Unity、XUILab 本地工程或 GitHub 凭证。
